الدخول الآمن

يمكنك الدخول كطالب عبر الهوية الرسمية، أو كعضو فريق عبر البريد وكلمة المرور. الجلسة تُحفَظ محليًا وتُجدَّد عبر refresh token عندما يكون ذلك مدعومًا.

ملاحظة: تسجيل الحسابات الجديدة من الواجهة غير مدعوم بعد، لكن مسارات login / refresh / logout / forgot-password أصبحت موصولة فعليًا.
